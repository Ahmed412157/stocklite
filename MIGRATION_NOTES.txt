StockLite PostgreSQL / Neon deployment

This version uses PostgreSQL through psycopg 3. Configure DATABASE_URL in Render using the Neon pooled connection string. Keep sslmode=require in the URL.

The Neon database is initially empty. SQLite stocklite.db is intentionally not uploaded and is not automatically imported. Create a user account after deployment, then add products. If you need existing SQLite records, request a separate data migration before using the hosted app.

Render environment variables: DATABASE_URL, SECRET_KEY (generated), COOKIE_SECURE=1.
